# 双盲诗生成器 · Blind Verse RNN

[中文](#中文) · [English](#english) · [下载](https://github.com/Sherlock-LXL/blind-verse-rnn/releases)

## 中文

字符级中文 LSTM 诗句生成器。同一模型从 `<BOS>` 独立采样两次，A/B 不共享 hidden state 或上下文；支持 1–3 汉字续写、收藏、取消收藏、复制与会话收藏管理。

### 运行

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

需要仓库中的 `data/processed/vocab_benchmark.json`，以及从 Release 下载并放入 `checkpoints/` 的 `best_finetuned_model.pth`。Windows x64 用户可直接运行 `BlindVerseRNN-1.0.0.exe`，无需安装。

### 模型与结果

单层 LSTM，embedding/hidden **1536**、dropout **0.1**、冻结词表 **5,160**，embedding 与输出层不共享权重。目标语料 train/val/test 为 **1,292 / 159 / 160** 句；外部预训练 train/val 为 **612,349 / 32,228** 句，共 **5,134,711** 个训练字符。

| 采样模式 | Temperature | Top-k |
|---|---:|---:|
| 稳健 | 0.55 | 5 |
| 适中 | 0.70 | 15 |
| 激进 | 0.90 | 30 |

| 最终评估（non-PAD token-average） | 结果 |
|---|---:|
| Validation loss | 3.7171 |
| Test loss | 3.3620 |
| Test perplexity | 28.85 |

训练日志的 batch-average loss（从零 5.3966、微调前 3.9668、最佳微调 3.7379）使用另一口径，且从零实验词表为 1,555，不能作为严格受控的直接比较。

### 训练与项目结构

```bash
python -m pip install -r requirements-data.txt
python -m src.prepare_data
python -m src.pretrain
python -m src.fine_tuning
python -m src.test
```

`src/` 包含目标/外部语料准备、从零训练、预训练、微调与测试。外部语料不随仓库提供；历史 `vocab_benchmark.json` 与 `pretrain_benchmark.txt` 为人工冻结，准备脚本不自动生成它们。预训练默认输出 `best_pretrained_model.pth`，最终微调从历史 `best_pretrained_model_645kdata.pth` 加载；新微调保存为 `best_finetuned_model_new.pth`。

## English

A character-level Chinese LSTM poetry generator. The same model samples independently twice from `<BOS>`, without shared hidden state or context between A/B. It supports 1–3-character continuation, favorites, removal, copying and session favorite management.

### Run

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Use the included `data/processed/vocab_benchmark.json` and download `best_finetuned_model.pth` from the Release into `checkpoints/`. Windows x64 users can run `BlindVerseRNN-1.0.0.exe` without installation.

### Model and results

One LSTM layer, **1536** embedding/hidden size, **0.1** dropout and a frozen **5,160**-character vocabulary, with untied embedding/output weights. Target train/val/test contains **1,292 / 159 / 160** lines; pretraining train/val contains **612,349 / 32,228** lines and **5,134,711** training characters.

| Sampling mode | Temperature | Top-k |
|---|---:|---:|
| Conservative | 0.55 | 5 |
| Balanced | 0.70 | 15 |
| Adventurous | 0.90 | 30 |

| Final evaluation (non-PAD token-average) | Result |
|---|---:|
| Validation loss | 3.7171 |
| Test loss | 3.3620 |
| Test perplexity | 28.85 |

Training logs use batch-average loss: 5.3966 from scratch, 3.9668 before fine-tuning and 3.7379 at best fine-tuning. The scratch run also uses a 1,555-character vocabulary, so these are not directly comparable controlled results.

### Training and structure

```bash
python -m pip install -r requirements-data.txt
python -m src.prepare_data
python -m src.pretrain
python -m src.fine_tuning
python -m src.test
```

`src/` covers target/external corpus preparation, scratch training, pretraining, fine-tuning and testing. External corpora are excluded. Historical `vocab_benchmark.json` and `pretrain_benchmark.txt` were frozen manually and are not generated by preparation scripts. Pretraining writes `best_pretrained_model.pth` by default; final fine-tuning loads the historical `best_pretrained_model_645kdata.pth` and saves new runs to `best_finetuned_model_new.pth`.
